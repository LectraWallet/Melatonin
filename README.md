# Melatonin

A rootless semi-untethered jailbreak for iOS 15.0 - 17.3.1 (arm64e), iOS 15.0 - 18.7.1, 26.0 - 26.0.1 (A12/A13) and iOS 15.0 - 18.7.1 (arm64).

Melatonin is a rebrand of [Dopamine](https://github.com/opa334/Dopamine) by opa334, with extra features: built-in TrollStore + Sileo installers, extra themes (Melatonin, Midnight), and one-tap respring.

Based on Dopamine by opa334. All credit for the jailbreak itself goes to opa334 and contributors.
